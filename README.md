# Estudio Mujeres de Poder

Mini app publicada en claude.ai (Artifact) para el canal Mujeres de Poder.

- `index.html`: la app (Radar de noticias y outliers, guion en 5 bloques, auditoría, packaging).
- `prompts/guion.txt`: prompt maestro del guion, adaptado a la app.
- `prompts/packaging.txt`: prompt de títulos y miniaturas, con personajes.txt y SEO.
- `prompts/memoria.txt`: preferencias fijas del canal.
- `prompts/anti-ia.txt`: reglas de escritura anti-IA.

Usa los conectores Nexlev y Parallel Search del usuario y la cuenta de Claude de quien la abre.
